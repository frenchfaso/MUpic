# Commodore 1702-inspired PAL profile

`1702-pal.slangp` contains independent settings for the unmodified, 19-pass
CRT Guest Advanced PAL shader by guest(r). No CyberLab preset is included.
The intended reference is an early-1980s Commodore 1702 using its rear
Luma/Chroma inputs, with a relatively sharp luminance channel, softer chroma,
PAL delay-line processing, brightness-dependent beam width, modest glow,
short phosphor persistence and a segmented RGB mask.

The tube, mask, gamma and curvature settings are a visual approximation;
they are not a calibrated reproduction of a particular PAL 1702. Different
1701/1702 revisions used different tubes, and the available service manual
describes NTSC models. Input RGB has already been generated by the C64 core;
this postprocess cannot recover the original analogue VIC waveform.

Sources:

- [Commodore 1702 user manual](https://gona.mactar.hu/Commodore/monitor/manuals/1702_Monitor_Users_Manual.pdf)
- [Commodore service manual](https://gona.mactar.hu/Commodore/monitor/schematics/1701-1702_Service_Manual_Preliminary_314004-001_%281984_Oct%29.pdf)
- [Guest Advanced PAL](https://github.com/libretro/slang-shaders/blob/master/crt/crt-guest-advanced-pal.slangp)
- [CyberLab's stated 1702 inspiration](https://forums.libretro.com/t/cyberlab-death-to-pixels-shader-preset-packs/35606/745)

`UPSTREAM.json` records the exact upstream commit, every resource and its
SHA-256. `tools/vendor_guest1702.py` in the Wolf64 workspace reproduces this
subset using the recorded commit. Upstream resources have not been edited.
The main Guest CRT passes are GPL-2.0-or-later; individual resources retain
their original licence headers. `COPYING-GPL-2.0.txt` contains the licence.
The surrounding emulator is GPL-3.0-or-later. Shader files must accompany
the executable; macOS bundles include them under `Contents/Resources/shaders`.
